# Client Initial Questions

Use these questions before starting a website security, DNS, or domain authentication investigation.

## 1. Reported Issue

1. What problem are you currently seeing?
2. When did the issue first appear?
3. Is the issue affecting the whole website or only specific pages?
4. Are visitors seeing browser warnings, redirects, errors, or suspicious content?
5. Have customers or users reported any problems?

## 2. Website and CMS

1. What platform is the website built with?
   - WordPress
   - Shopify
   - Wix
   - Custom website
   - Other / unknown
2. Do you have admin access to the CMS?
3. Were any plugins, themes, or extensions recently installed or updated?
4. Were any developers, agencies, or contractors recently involved?

## 3. Hosting and Server Access

1. Who is the hosting provider?
2. Do you have access to the hosting control panel?
3. Do you have SSH or FTP/SFTP access?
4. Do you have recent server or access logs?
5. Has the hosting provider sent any security warnings?

## 4. Domain and DNS

1. Who is the domain registrar?
2. Do you have access to the domain registrar account?
3. Who manages DNS records?
4. Were DNS records changed recently?
5. Are nameservers pointing to the expected provider?

## 5. Email and Domain Authentication

1. Is the issue related to email delivery or domain authentication?
2. Which email service do you use?
   - Google Workspace
   - Microsoft 365
   - Mailchimp
   - SendGrid
   - Other
3. Do you need SPF, DKIM, or DMARC reviewed?
4. Are emails going to spam or failing authentication?

## 6. Backups and Recovery

1. Do you have a recent clean backup?
2. When was the last known good version of the website?
3. Has any restore attempt already been made?
4. Are there backups from the hosting provider?

## 7. Security and Access

1. Have all admin passwords been changed recently?
2. Are there any unknown admin users?
3. Is two-factor authentication enabled where possible?
4. Are there old user accounts that should be removed?

## 8. External Warnings

1. Is there a Google Search Console warning?
2. Is there a Google Safe Browsing warning?
3. Has the website been flagged by browsers or antivirus tools?
4. Are there warnings from the hosting provider, email provider, or domain registrar?

## 9. Desired Outcome

1. What is the most urgent outcome?
   - Restore website availability
   - Remove suspicious redirect
   - Fix DNS/domain issue
   - Fix email authentication
   - Review possible compromise
   - Prepare a report
2. Are there any changes that should not be made without approval?
